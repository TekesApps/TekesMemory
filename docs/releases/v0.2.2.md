# TekesMemory v0.2.2

日期：2026-10-29。发布跟踪 [Issue #11](https://github.com/TekesApps/TekesMemory/issues/11)。
源码 tag：`v0.2.2`（`vx.y.z` 格式）；
[GitHub Release](https://github.com/TekesApps/TekesMemory/releases/tag/v0.2.2)。
本次发布源码及 GitHub 自动生成的源码归档，不发布 crates.io 包或预构建二进制资产。
下述安装二进制仅作为本机验收产物。

## 修复

包含 [PR #10](https://github.com/TekesApps/TekesMemory/pull/10) 对 #3–#9 的全部修复：

- 原始日志来源、observation 身份和上游依赖分开保留，遗忘/来源失效清理已处理与待处理闭包，防止后台任务重新发布被删除内容。
- 只对内容脱敏，scope、来源、事件和幂等身份保持精确值。
- 长正文可通过预算内片段发现，完整正文仍由 get 提供；分页保留未消费的命中。
- 完整文档索引与查询的 256 token 限制分离，已有索引按版本标记重建。
- 请求 2 MiB、响应 8 MiB 分别有界，派生写入在入队前检查完整读取封装。
- HTTP/stdio 的 JSON-RPC ID 保留整数精度，支持 i64 和字符串，超范围数字返回协议错误。
- 更新相关 TLS/Tokio 锁定依赖，消除本组 RustSec 版本命中。

数据库 user_version 和业务 schema_version 仍为 1。observation 新增可选来源元数据，
需要服务和 adapter 配套升级；仅替换服务无法让旧 adapter 补交从未记录的来源身份。

## 安装及配套升级

```sh
git checkout --detach v0.2.2
cargo install --path . --locked --root /absolute/tekesmemory-v0.2.2
/absolute/tekesmemory-v0.2.2/bin/tekes-memory --version
```

应输出 `tekes-memory 0.2.2`。同一个已安装二进制的 `serve` 提供服务、`kernel` 提供 adapter，
无需安装两个独立包。升级顺序：

1. 停止旧服务并备份私有配置和 data，保留权限；先在副本验证。
2. 在新固定版本目录安装，服务继续使用已有 service.json/data；不要对已有目录重新 init。
3. 五个 hook 的 argv[0] 全部改为同一个新二进制路径，保留 adapter 配置、host_instance_id、
   scope、凭据和 hook 其他策略字段。同步更新 stdio/launchd 使用的可执行文件路径。
4. 宿主重新捕获新的 hook bindings，再验证读取、检索和一次真实采集/遗忘链路。

旧版丢失的隐式聚合来源身份无法安全自动恢复；已有 payload 中保留的显式来源键可在失效时
跟随清理。索引重建不等于恢复缺失来源。回退应恢复升级前匹配的配置与数据备份。

## 配套升级验证

在 macOS arm64 / Rust 1.95.0 上，分别从 `v0.2.1` 和本版 locked 源码执行真正的
`cargo install --path . --locked`，从源码目录外、空环境启动安装后的二进制。
测试使用新建隔离配置/数据库，不操作实际 SKZY 候选服务或生产数据。

| 验证 | 实测结果 |
|---|---|
| 旧服务写入与停止 | 0.2.1 写入含 300 个不同 token 的合法记录，尾词检索未命中；SIGTERM 成功退出 |
| 备份与身份 | 配置/data 副本及文件模式保留；升级前后凭据哈希、scope、owner、host_instance_id 不变 |
| 新服务读取/索引 | 0.2.2 使用同一配置和 data，旧 ID/revision/正文保持，旧尾词可检索到原 ID |
| 五个 hooks | 五个绑定 argv 全指向安装后的 0.2.2，其他身份/策略字段不变 |
| 真实新 adapter | 执行 tool.completed(seq=5) 和 turn.settled(seq=7)，明确区分 tool_result 与 turn_outcome；遗忘实际工具记录同时清除依赖摘要 |
| 重启 | 遗忘后重启，两个派生 ID 均 not_found，标记不可检索；旧记录仍完整 |
| 全目标测试 | 83 项集成通过，2 个 SDK 默认 ignored 后单独执行通过；lib/bin/examples 独立单元均为 0 项 |
| 安装后的官方 SDK | TypeScript SDK 1.30.0 对安装后的 0.2.2 HTTP/stdio 完成 initialize/list/save/get/search/close，各通过一次 |
| 安装 smoke | 空环境、源码目录外 init/HTTP save/真实 context.prepare hook/plist 路径验证通过；未启用 launchd |
| 静态与依赖 | Clippy -D warnings、fmt、diff 通过；258 个依赖审计 0 漏洞/unsound，另有 yoke-derive 0.8.3 yanked 提示 |

复现配套升级：

```sh
cargo run --locked --example upgrade_smoke -- \
  /absolute/tekesmemory-v0.2.1/bin/tekes-memory \
  /absolute/tekesmemory-v0.2.2/bin/tekes-memory \
  /absolute/private-upgrade-evidence
```

第三参数下生成独立 fixture、备份和脱敏 summary。该目录仍含测试凭据，应私有保留，
不要上传整目录；发布证据仅保存脱敏摘要。
